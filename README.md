# Sophie Fit

Eine kleine Web-App (PWA) für Sophies Weg von der Rückbildung zu einem vollständigen Training mit Kraft, Ausdauer und HIIT, dazu Ernährung als alltagstauglicher Mittelweg und ein wöchentliches Coaching.

**App öffnen:** https://flohoecherl-star.github.io/Fit-Sophie/

Auf dem Handy im Browser öffnen und „Zum Home-Bildschirm hinzufügen“ wählen. Dann läuft sie wie eine App, auch offline.

## Was drin ist

- **Heute:** die Einheit des Tages, Beckenboden-Routine, Wochenübersicht, Coaching-Tipp der Woche
- **Plan:** vier Phasen (Fundament, Aufbau, Laufstart & HIIT, Vollplan) mit Wochenplan, Übungen und Kriterien zum Abhaken
- **HIIT:** sechs Intervall-Workouts mit Vollbild-Timer und Signalton, je nach Phase freigeschaltet
- **Essen:** 80/20-Prinzip, Teller-Regel, Eiweiß, Stillen, Energie-Räuber (Eisen, Jod, Omega-3, Vitamin D), Snacks, Meal-Prep
- **Coach:** Wochen-Check-in mit Rückmeldung, Coaching-Themen, Tipps für den Partner, Hilfe bei Wochenbettdepression, Einstellungen

Alle Daten bleiben im Browser auf dem Gerät. Über „Daten sichern“ lässt sich eine Sicherung herunterladen und auf einem anderen Gerät laden.
